# Data Analytics & Business Intelligence Projects

## About This Repository

Welcome to my Data Analytics and Business Intelligence portfolio.

This repository contains a collection of data-related projects focused on exploring, analysing, transforming and visualising data to generate meaningful insights and support data-driven decision-making.

The projects demonstrate my practical experience and continuous development in data analytics, business intelligence and data science.

## Areas Covered

- **Data Analytics:** Exploring datasets, identifying patterns and extracting meaningful insights.
- **Business Intelligence:** Developing dashboards and reports to monitor performance and support decision-making.
- **Data Cleaning & Transformation:** Preparing raw data for accurate and reliable analysis.
- **Data Visualisation:** Presenting information through interactive charts, reports and dashboards.
- **Data Science:** Applying Python and analytical techniques to investigate data and solve problems.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Python
- SQL
- Microsoft Excel

## Projects

This repository contains individual projects covering different aspects of data analytics and business intelligence.

Each project has its own folder containing relevant documentation, resources and project files.

## Purpose

To demonstrate my ability to work with data throughout the analytical process, from data preparation and exploration to visualisation, interpretation and communicating insights.
